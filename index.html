Architecture & OS Constraints

100% Offline & Free Architecture

WakeGuard requires ₹0 and no cloud server. Alarms and streaks reside in LocalStorage. Uploaded MP3/WAV song files reside in browser IndexedDB. Sounds play via native Web Audio API oscillators or local blob audio tags.

Anti-Mute & Anti-Cheat Safeguards

The alarm volume is enforced with a strict hardware clamp (≥65%). While the alarm is ringing, keyboard volume-down/mute shortcuts are blocked on laptops/desktops, and a JavaScript watchdog continuously ramps the audio gain back up if lowered.

Browser Mobile Limitations (Android & iOS)

Mobile OSs intentionally throttle background JS when tabs are closed. For guaranteed waking: keep WakeGuard open overnight in the active tab with Screen Stay Awake enabled.
